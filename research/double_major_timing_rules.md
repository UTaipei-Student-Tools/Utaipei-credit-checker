# 北市大雙主修／輔系申請時點與適用規則證據報告

調查日：2026-09-01（臺灣時間）  
範圍：臺北市立大學（UTaipei）教務處／註冊組現行及可取得的歷年規章、學則、公告、表單，以及地生系、應用物理暨化學系（APC）、資訊科學系、數學系的官方頁面與手冊。目標是支援 111–115 入學或申請情境的規則引擎；本報告不是校方個案畢業資格核定。

## 結論先行

目前官方證據可以確定三個不同的時間軸：

1. **目標課程／畢業門檻：以入學學年度手冊為主要依據。** 數學系明文要求依入學學年度下載手冊；地生系公開頁面也按 111、112、113、114 等入學年分列手冊。這不等於雙主修辦法本身有同樣的過渡條款。[數學系課程與修課須知（擷取 2026-09-01，頁面未標公告日）](https://math.utaipei.edu.tw/p/412-1082-146.php?Lang=zh-tw)（「依入學之學年度下載課程手冊」）；[地生系學生手冊頁（頁面日期 2024-10-29）](https://envir.utaipei.edu.tw/article_detail/6)。
2. **能否在某學期送件：以該學期公告的實際窗口為準。** 現行雙主修辦法只寫「每學期依校曆及公告」申請，沒有把日期固定成每年相同的永久規則。[學生修讀雙主修辦法（現行，修訂沿革至 115/05/22；PDF 第 1 頁，第 2、3 點）](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/316980591.pdf)。
3. **111–115 普通入學生究竟適用哪一版校級雙主修辦法：官方文本沒有解決。** 現行 PDF 沒有一般學生的 cohort／過渡條款；學則第 4 條只處理 102/7/31 前入學者及 102/8/1 後轉學生。因此程式不能僅以「入學年」或「申請年」自動替學生選定 115.06 版。[北市大法規清單（現行雙主修標示 115.06，擷取 2026-09-01）](https://reg.utaipei.edu.tw/p/412-1031-2.php?Lang=zh-tw)；[學則（現行，修訂至 115/05/22；PDF 第 2 頁，第 4 條）](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/108163803.pdf)。

所以產品狀態必須分開保存：`admission_cohort`（課程手冊）、`application_term`／`submitted_at`（送件窗口）、`rule_version`（校級規章）、`target_department_approval`（系所審查）及 `effective_term`／`registrar_registered`（正式生效）。任何一項沒有官方證據，就應顯示 `UNKNOWN`，不能以往年日期或課名相似度補猜。

### 版本適用判斷

教務處法規清單目前把雙主修辦法列為 115.06，現行 PDF 的修訂沿革列有 102/12/24、103/06/17、104/06/16、109/06/16、112/03/21、112/05/09、112/06/20、115/03/31、115/05/22；但 PDF 沒有「某入學年以前／以後適用」的過渡條文。[法規清單（擷取 2026-09-01）](https://reg.utaipei.edu.tw/p/412-1031-2.php?Lang=zh-tw)；[現行雙主修辦法](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/316980591.pdf)（PDF p.1，修訂沿革）。因此對 111、112、113、114、115 普通入學生，**目前可確定的是目標課程手冊按入學年分流；校級雙主修辦法的版本適用仍為 UNKNOWN**。需向註冊組確認應以招生／入學 cohort、申請日、系所核准日、教務處登錄／生效學期，或組合條件判定。

### 已核對的歷史版差異

109 年版雙主修辦法第 11 點仍有「延長修業年限期間不及格學分數達退學規定」的退學處理文字；現行版的修訂對照表記載，因 114/12/30 校務會議刪除該段，現行第 11 點改為延修後的畢業處理，條次並順移。[109 年版雙主修辦法](https://reg.utaipei.edu.tw/var/file/31/1031/attach/25/pta_79080_7602935_29189.pdf)（PDF p.2，第 11 點；修訂沿革至 109/07/21）；[現行雙主修辦法修訂對照表](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/316980591.pdf)（PDF p.4，修訂說明；現行修訂至 115/05/22）。這是「規章版本有實質差異」的證據，但不是 111–115 普通入學生應套用哪一版的過渡規則；後者仍 `UNKNOWN`。

## 四、重疊、替代與「學分可移動」的可實作邊界

官方允許在符合性質、額度與系所決定的前提下重新分配，但不是任意搬移：雙主修辦法第 6 點的共用是每方向最高 6 學分且由加修系決定；不足時依加修系規定補修替代科目；放棄後移入選修又需要相應系主任決定。[雙主修辦法](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/316980591.pdf)（PDF pp.1–2，第 6、10 點；修訂沿革至 115/05/22）。因此規則引擎應採「逐課資源分配」：

1. 先以入學年手冊建立目標需求列（必修、專業選修、共同／自由學分、替代候選）。
2. 對每門成績單課程保留唯一來源 ID、課號、名稱、學分、學期、成績及課程大綱證據；同一來源不可同時滿足兩個目標列。
3. 課名相近只產生 `candidate_mapping`；「普物／普化」是否等於目標的「普通物理學（一）／普通化學（一）」、講授是否包含實驗，都要分開列課並交由目標系所核准。[現行雙主修辦法](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/316980591.pdf)（PDF p.1，第 5、6 點；修訂沿革至 115/05/22）。
4. 若加修系核准原主修系訂必修共用，消耗對應方向的 6 學分上限；若未核准，來源課回到可用池，但只能依原主修系規則重新放入自由／選修，不可自動變成目標專業必修。
5. `waiver`（免修但不給目標學分）、`credit_transfer`（取得目標學分）、`department_approval`（待系所決定）及 `rejected` 要分開。數學系公開修課須知明示外系／外校課程與免修、替代採認需依程序，且雙主修／輔系有外系選修上限；[數學系課程與修課須知](https://math.utaipei.edu.tw/p/412-1082-146.php?Lang=zh-tw)（擷取 2026-09-01，頁面未標日期）。

## 六、實作準備用狀態機

以下是建議的資料狀態機，不是把 UNKNOWN 當成通過；每一個轉移都應攜帶 `source_url`、`source_kind`、`page_or_article`、`published_or_retrieved_at`。

```text
PROFILE_INCOMPLETE
  ├─缺 admission cohort / level / home-target / transfer 資料──────────────┐
  └─資料齊全                                                            │
       ↓                                                               │
ELIGIBILITY_UNKNOWN ───────────────┐                                   │
INELIGIBLE                         │                                   │
ELIGIBLE_TO_APPLY ────────────────┘                                   │
       │（官方學期公告及目前日期）                                      │
       ├─缺公告／年級文字衝突 → WINDOW_UNKNOWN                          │
       ├─尚未開放 → NOT_YET_OPEN                                       │
       ├─窗口內 → WINDOW_OPEN                                          │
       └─已截止 → WINDOW_CLOSED                                       │
       ↓（送件）                                                       │
SUBMITTED → DEPT_REVIEW → DEPT_APPROVED / DEPT_REJECTED                │
       ↓（教務處正式登錄，且有生效學期）                                │
REGISTRAR_REGISTERED → ACTIVE → PROGRESS_REVIEW                        │
       ├─目標學分／原主修／校級條件不足 → PROGRESS_INCOMPLETE            │
       ├─資料缺漏或版本未定 → GRADUATION_UNKNOWN                        │
       └─全部達成並經正式畢業審核 → DOUBLE_MAJOR_GRANTED               │

ACTIVE / PROGRESS_REVIEW
       └─放棄申請 → WITHDRAW_REQUESTED
          ├─逾 12/25、5/25 且無例外核准 → WITHDRAW_REJECTED
          ├─例外證據及教務處核准 → WITHDRAWN（不可恢復）
          └─符合輔系且重新核對 → MINOR_CONVERSION

放棄後原主修完成 → HOME_DEGREE_ONLY
放棄原主修且目標完成 → TARGET_DEGREE_ONLY（須依校方程序）
```

最小輸入集合：

- 身分：學士／研究所、入學 cohort、轉學生及轉入年級、原主修／組別、目標系／組別、正常修業年限、請假／復學／延修區間。
- 申請事件：申請學年度／學期、`submitted_at`、官方公告 URL 與日期、文件提交、系所面談／審查、系所核准日、教務處登錄日、正式生效學期、申請次數。
- 版本：雙主修／輔系辦法版本及公布／修訂日、入學年手冊 URL、系所課程／名額／審查公告；若官方沒有 transition decision，保存 `UNKNOWN`。
- 成績：每門來源課程及目標映射、必修／專業選修／共同／自由分類、共用方向與上限、免修／抵免／替代的證據及核准人。

狀態判定原則：

- `ELIGIBLE_TO_APPLY` 只表示符合已核實的申請資格，不表示系所會錄取；資科系面談通過要求即是例子。[資科系官方公告](https://cs.utaipei.edu.tw/p/405-1081-116948%2Cc3219.php?Lang=zh-tw)（113-2，窗口 113/09/30–10/08，公告日未顯示）。
- `WINDOW_OPEN` 只能由該學期公告的精確日期／時間產生；沒有公告不可建立週期性日期。[雙主修辦法](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/316980591.pdf)（PDF p.1，第 3 點；修訂至 115/05/22）。
- `ACTIVE` 需要 `REGISTRAR_REGISTERED` 與 `effective_term`；輔系可依規章採次學期開始，雙主修則待註冊組確認。[輔系辦法](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/316943067.pdf)（PDF p.1，第 4、5 條；修訂至 112/07）。
- `DOUBLE_MAJOR_GRANTED` 只在原主修、目標課程、校級畢業條件及正式畢業審核均通過後產生；規劃器不能把「40 學分」單獨當成學位結果。[學則](https://reg.utaipei.edu.tw/var/file/31/1031/img/926/108163803.pdf)（PDF p.6，第 44、46 條；現行修訂至 115/05/22）。
