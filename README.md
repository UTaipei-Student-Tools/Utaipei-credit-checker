# 北市大畢業通

幫臺北市立大學學生整理成績、核對畢業學分，看看還缺哪些課，也能規劃輔系與雙主修。

**[開啟網站](https://utaipei-credit-checker.streamlit.app/)**

## 可以做什麼

- **查本學期課程**：先選星期與節次，再篩選科系、年級、通識或共同選修。
- **整理成績**：上傳歷年成績單 PDF，或選用校務系統登入。通識集中在上方，其他課程依學期、必修與選修排列。
- **核對畢業進度**：按類別查看已採計與尚缺學分；未修課程達三門時，可點紅色缺額區塊展開清單。選修清單是可選課程，不代表每門都要修。
- **規劃輔系與雙主修**：分區查看要求與進度，不和主修混在一起。
- **下載結果**：匯出 PDF 報告、CSV 明細或 JSON 判定摘要。

## 怎麼使用

1. 按「開始檢查」，向下進入工作區。
2. 選擇入學年度、主修及輔系／雙主修設定，再按「套用設定」。預設年度為 113。
3. 匯入成績，檢查解析結果；有錯誤可展開編輯。
4. 按「確認目前成績列」，查看下方畢業審核與缺額。

查課可單獨使用，不必先匯入成績。返回封面不會清除本次資料。

## 使用前請注意

- 本工具供個人規劃與初步核對，**不取代校方正式審查**。
- 修習中、退選／停修與已取得學分分開處理；資料不足會提示核對，不直接當成通過。
- 113 地生手冊與 114 資科雙主修規定已標示為「已確認資料」，不得由同步或自動更新任意覆寫。這不代表個人的畢業或雙主修資格已獲核准。
- 查課資料是擷取時的紀錄，不代表即時名額或個人選課資格。
- 請勿將真實成績單、密碼或權杖提交到公開專案；使用共用電腦後，記得清除資料與下載檔案。
